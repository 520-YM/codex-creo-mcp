## 第1步：连接并读取现状

**目的：确保改的是你刚打开的 Creo 和你选定的工作目录。**

指令顺序：

1. `creo_start_resident_and_get_basic_model`
2. 需要打开总装配时：`creo_open_top_assembly`
3. 需要补充组件和尺寸时：
   - `creo_get_project_assembly_components`
   - `creo_get_project_dimensions`

读取内容：

- Creo 进程身份和启动时间。
- 当前工作目录。
- 当前总装配。
- 骨架名称。
- 骨架长宽。
- 当前启用的屏。
- 本次会涉及的玻璃、风扇、过滤棉、铰链、气弹簧。

当前这套模型的基本对象是：

- 总装配：`M26Z0100000-V01.ASM`
- 骨架：`M26Z0100000-V01_SKEL.PRT`

**完成条件：**真实读到上述信息，且确认目标模型属于当前工作目录。不能用昨天的读取结果代替今天的读取。

## 第8步：风扇数量、间距和中心对称

这一项以你明确教过的对象为准，不能再把进风、出风、屏前混淆。

### 8.1 出风仓

操作对象：

**`M26Z0181020-V01.PRT → 阵列3、拉伸8`**

本机候选源码里的映射：

| 对象 | 特征 ID | 关键尺寸 |
|---|---:|---|
| 阵列3 | `1698` | `d67`：阵列间距 |
| 拉伸8，种子特征 | `1603` | `d65`：种子定位尺寸 |

刚才这次实际读到：

- `d67 = 196 mm`
- `d65 = 490 mm`

**但这两个数本身不能替代实际风扇数量读取。**

源码已有候选指令：

`creo_set_outlet_part_pattern_preserve_span`

主要参数：

- `expected_count`：实际旧数量。
- `new_count`：目标数量。
- `expected_spacing`：旧间距。
- `expected_seed`：旧种子位置。
- `inspect_only`：先检查还是实际修改。

底层候选命令为：

`OUTLETPATTERN`

**当前限制：该候选没有出现在本次可调用的 MCP 工具列表里；源码还设置了验证前禁止写入的条件，不能把它当成已经上线。**

具体调整逻辑：

1. 实际读取阵列和装配中的风扇数量。
2. 根据“减一个”计算目标数。
3. 同时处理阵列间距和种子位置，保持中心对称。
4. 回总装配重新生成。
5. 读取实际风扇、安装件和对应孔位，验证同步。

例如，**如果实际核实是6个，中心位置确实为±490、±294、±98 mm**，并采用保留两端跨度的方案：

- 原跨度：980 mm。
- 改5个的间距：`980 ÷ 4 = 245 mm`。
- 位置应为：`−490、−245、0、245、490 mm`。

这是有前提的计算示例，**不是说刚才已经核实数量或改好了**。

### 8.2 进风仓

按你指定：

**`M26Z0181080-V01.PRT → 阵列2`**

流程同样是：

实际数量 → 目标数量 → 间距与起始位置 → 中心对称 → 总装配再生 → 实际成员读回。

目前我没有核实到这套当前模型“阵列2”的具体数量字段、间距符号及对应可用写入指令，不能编造。

### 8.3 第8步的完成标准和失败处理

必须同时确认：

- 数量正确。
- 左右对称。
- 间距合适。
- 安装孔、安装件、防护网与风扇同步。
- 没误改独立加热风扇或其他风扇组。

按你后来的明确要求：**第8步做不了，记录未完成，先继续后面的独立步骤，不能把整个14步卡住。**

## 第10步：前框气弹簧——严格按你规定的顺序

**固定顺序：读取质量 → 计算并选型 → 改气弹簧 → 改骨架支架位置 → 验证极限、角度和支撑力 → 不合格继续调整。**

### 10.1 确认前框活动质量

历史映射的前框装配：

`M26Z0141002-V01.ASM`

必须先确认它确实是当前随前框转动的组件，不把后箱体、固定电器等全部算进去。

质量读取指令：

`creo_get_mass_properties`

范围包括实际随前框运动的框体、玻璃、支架、紧固件等。

按你的要求，缺材料的零件可以排除，但必须列出：

- 排除了哪些件。
- 计算采用的质量是多少。
- 这是排除后的计算质量，不冒充完整实测质量。

不能每次都套用历史的31.54 kg。

### 10.2 读取力学和运动几何

需要：

- 铰链轴的位置、方向。
- 活动组件重心。
- 两根气弹簧固定端和活动端安装点。
- 气弹簧实际伸长、压缩极限。
- 装配滑块极限。
- 正确开门方向。

**不能仅测你当前屏幕上门打开了多少度。**需要用机构极限和安装几何计算关闭状态、最大开启状态。

### 10.3 选型号

同时选择：

- 中心距。
- 行程。
- 单根推力。
- 端部规格。
- 两根的安装适配关系。

若你要求“短一点的行程”，必须在满足开闭条件的候选中优先选择，不能只改型号名字。

力矩基本校核：

- 重力力矩：`Tg = m × g × 重心垂直力臂`
- 支撑力矩：两根气弹簧各自有效力矩相加。

左右几何相同时，才可简化为：

`Ts = 2 × 单根推力 × 有效力臂`

### 10.4 先把气弹簧本体改好

当前工具中有：

`creo_create_project_gas_spring_variant`

该指令要求核对旧装配、旧UP/DOWN名称，以及旧行程、补偿距离和滑块极限。

同步处理：

1. 气弹簧装配名称。
2. `YQLDOWN` 名称和行程。
3. `YQLUP` 名称和行程。
4. UP补偿距离。
5. 滑块最大限制。
6. 实际装配的两根是否都更新。
7. 再生、读回。

**这不是通用的“任意型号一键替换”指令；不同端部直径或结构变化，还要确认实体几何确实改变，不能只改名字。**

### 10.5 再调骨架位置

按你指定的主要位置：

`M26Z0100000-V01_SKEL.PRT → 后盖气弹簧支架`

| 项目 | 映射 |
|---|---|
| 特征 ID | `6918` |
| 主要位置尺寸 | `d191` |

对应指令：

`creo_modify_project_feature_dimensions`

优先调整这里，使气弹簧在关闭时不会提前压到底，同时打开角度合适。

只有主要位置不足以实现要求时，才考虑骨架：

`前框气弹簧支架 → ID 121844 → d493`

**只改安装位置，不擅自改支架结构拉伸长度。**

### 10.6 验证，不合格就调整

本机规则目标：

- 最大开启角度：50°，允许±5°。
- 关闭压缩余量：约10 mm。
- 最大开启能支撑。
- 关闭方向正确，不向后翻。
- 关闭过程不因行程到底而关不上。
- 检查开启过程的干涉和力矩变化。

关闭余量应按实际极限定义计算：

`关闭时两端中心距 − 实际最短中心距`

不能未经核对就假定型号中的中心距减行程一定等于实际最短安装中心距。

**改了型号或支架位置，不等于第10步完成。上述验证缺项，就必须明说。**

## 第11步：屏组件气弹簧——与前框采用同一流程

### 11.1 活动组件

`M26Z0163001-V01.ASM`

质量包括：

- 当前活动屏本体。
- 屏安装框架。
- 随屏运动的其他零件。

屏本体可使用已确认的知识库质量，但必须匹配当前屏规格，并明确来源；不能把65寸屏的20 kg套给49寸、55寸。

缺材料件按你授权排除，报告排除范围。

### 11.2 找到实际的两根气弹簧

历史记录中的实际型号曾为：

`YQL300-110-18-8-220N`

但它只是历史型号，**不是固定正确答案**。

还要区分：

- 真正产生支撑的气弹簧实体。
- `YQL-D_` 等机构占位模型。

不能把占位件改了，就说两根实物气弹簧都换好了。

### 11.3 执行顺序

与第10步一致：

**质量 → 几何与力矩 → 型号 → 两根本体修改 → 骨架位置 → 极限验证。**

气弹簧本体变型可使用：

`creo_create_project_gas_spring_variant`

同样必须核对其适用范围和两根的实际引用。

### 11.4 调整骨架的指定位置

`M26Z0100000-V01_SKEL.PRT → 屏组件气弹簧支架`

| 项目 | 映射 |
|---|---|
| 特征 ID | `101924` |
| 主要位置尺寸 | `d405` |
| 同特征其他尺寸 | `d403、d404`，不能未经核对一起改 |

对应指令：

`creo_modify_project_feature_dimensions`

主要位置无法满足要求时，规则还有一个备用调整点：

`M26Z0181090-V01.PRT → 屏组件气弹簧支架孔位`

- 历史特征 ID：`1187`
- 主要位置尺寸：`d70`

但你指定的是优先修改骨架“屏组件气弹簧支架”，不能跳过它直接乱改其他位置。

### 11.5 验证

- 屏组件能够完整关闭。
- 有合理压缩余量。
- 最大开启能支撑。
- 两组都按各自最大开启状态比较。
