# 撤销与常驻桥接

## 现象

启用持续轮询的同步 Pro/TOOLKIT DLL 后，Creo 主界面的撤销按钮可能保持灰色，`Ctrl+Z` 无法撤销已提交操作。

## 原因

同步 Pro/TOOLKIT 调用会影响 Creo 主会话的撤销/重做栈。常驻 DLL 如果通过高频 UI 定时器持续进入 Toolkit，即使没有模型写入，也可能不断清空主撤销栈。

## 处理选择

1. **优先速度**：启用常驻 DLL，接受原生撤销能力可能受影响。
2. **优先撤销**：不自动加载常驻 DLL，改用按需异步桥接。
3. **长期方案**：重构为事件驱动或一次性桥接，避免空闲轮询进入 Toolkit。

`max_undo 5` 只能设置撤销深度，不能解决常驻 Toolkit 调用清空撤销栈的问题。

## 安全原则

- 不要为了修复撤销而覆盖用户完整 `config.pro`。
- 不要自动停用、删除或重写 WJT276。
- 修改配置前列出准确行和影响，并获得用户明确许可。
- 保留配置备份，但不要把真实配置上传到 GitHub。
