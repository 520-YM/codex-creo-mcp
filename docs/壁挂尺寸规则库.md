# 横屏内贴玻璃户外壁挂尺寸规则

单位：mm。尺寸顺序统一为“长 × 宽”。

| 屏幕规格 | 壁挂外尺寸（长 × 宽） | 状态 |
| --- | ---: | --- |
| 43 寸 | 1245 × 815 | 用户于 2026-09-14 更新确认 |
| 49 寸 | 1304 × 914 | 已确认 |
| 55 寸 | 1440 × 990 | 已确认 |
| 65 寸 | 1660 × 1113 | 已确认，2026-09-09 更新 |
| 75 寸 | 1995 × 1158 | 已从最新版表格确认 |
| 86 寸 | 暂不处理 | 按用户要求忽略 |

## 执行约定

- 用户说“切换到某尺寸横屏内贴玻璃户外壁挂”时，采用本表对应的壁挂外尺寸。
- 未特别指定壁挂圆角时，默认使用 R0.5 mm；明确指定 R10 mm 时才改为 R10 mm。
- 没有经过用户确认的尺寸不得自行推算或写入模型。
