# 聊天记录学习与14步严格落实

整理日期：2026-10-27。来源：用户在本任务提供的长期 Creo 操作与纠错对话。仅整理执行知识，不上传聊天原文、截图、账号、公司模型或私密原始资料。

## 1. 适用范围与规则修订

本文件用于横屏内贴玻璃户外壁挂改型。通用授权见规则01，气弹簧计算细节见规则15。不是新增运行能力，也不是当前模型已通过的证明。
区分三类证据：用户明确要求、须现场复核的模型映射、带日期的历史观察。当前明确指令优先；现场 API 决定当前状态，不能把测量事实解释为新的授权。

本次明确修订旧规则：第8步无法完成时先记录并继续安全独立步骤；第10、11、12步不得默默省略；第14步未全部通过也应保存可安全保存的状态；缺材料零件按用户允许排除但列明质量范围；气弹簧执行顺序为先质量、选型、换型，再调整骨架支架。不适用的旧描述不能覆盖这些明确要求。
不跳过不等于无限重试或带病写入：真实阻塞必须报告未完成；不得虚报验收，也不得绕过规则01。

## 3. 尺寸、屏体与玻璃

- 用户明确外尺寸：49寸1304×914 mm、55寸1440×990 mm、75寸修订为1995×1223 mm。其他规格读取正式尺寸库，不猜填。
- 切换49寸时恢复49inch并隐含不适用屏体；55寸同理，不能多个规格误启用。
- 玻璃内外尺寸和名称必须对应目标规格。使用 Creo 模型重命名维护引用，不通过资源管理器改名。
- 改名后及时保存相关父装配并核对引用。子件已改名而父装配未保存，会在重开后形成旧名引用风险。
- 不把用户一次允许试改方向，当作长期免除 VESA 方向检查。

## 4. 风扇、过滤棉、铰链的具体操作知识

### 出风仓

用户指定驱动零件 `M26Z0181020-V01`，修改“阵列3”及“拉伸8”的相关间距、范围与种子位置，保持中心对称。不能误改屏前或进风仓风扇。
填充阵列不一定有独立数量尺寸；实际数量由间距、区域和种子位置决定。修改后回总装配再生并统计真实风扇数。“加1”以当前实测数量为基准。

### 进风仓

用户指定 `M26Z0181080-V01` 的“阵列2”。同时检查风扇、防护网数量、边界余量、位置与对称性。
旧对话中55→65出风加1、进风加3属于特定起始配置经验，不是所有模型通用公式。

### 屏前风扇与均布

用户要求解决两边留白过大，不能只保证中间等距。可用宽W、风扇宽b、数量n，若采用两端与内部等净空，则 g=(W-n*b)/(n+1)，中心距p=b+g。W须扣除禁布区域；g不足时重新选数量。此为均布计算方案，不是固定设计标准。
奇数通常中间一个、左右成对；偶数通常左右成对。用实际中心坐标检查，不靠截图。

### 过滤棉

按空间、等级和正式规格选型，不沿用上一尺寸过大的过滤棉。安装开口与本体同步处理；检查框架以及褶皱/曲面等全部外形。实体框架包络正确不代表内部褶皱没有越界。
历史曾通过修改褶皱间距解决越界，但该数值不能固化为所有规格。

### 铰链

用户指定修改骨架“铰链阵列”。5改4等任务须实际改数量布局并读回实例，不是隐藏一个。间距按空间和用户要求扩大并检查安装孔；约300mm是参考，不应压过明确的当前布局要求。

### 映射保护

上述名称是用户提供的语义查找入口，不是永久ID。每次核对模型、特征归属、尺寸方向、旧值、关系驱动状态，再写入。历史d编号、PID、文件版本和坐标不得盲用。

## 5. 第10、11步：两组气弹簧严格顺序

1. 确认目标运动组件、铰链轴及两侧气弹簧身份，不混淆前框与屏组件。
2. 读取运动质量与重心。前框仅统计随前框运动件；屏组件仅统计随屏组件运动件，隐含屏不计入。
3. 缺材料零件可按用户明确允许排除，但列出零件和原因；重心必须对应同一计入范围。结果称“排除后的计算质量”，不能称完整真实质量。非材料原因的读取错误不能一律当成缺材料忽略。
4. 屏体可用已确认的对应尺寸知识库质量，标明来源，避免和几何质量重复计入；屏体重心缺失时明确估计假设，不伪装实测。
5. 从正式型号库选择长度、行程、接口和推力，明确完整型号。不能只用总推力与重量比较，也不能编造规格。
6. 先实际切换两根气弹簧。核对装配及UP/DOWN名称、内部行程、补偿、滑块限制、接口、伸缩方向与约束；只改名称不算换型。
7. 再调整骨架安装位置：前框优先“后盖气弹簧支架”，必要时小范围调整“前框气弹簧支架”；屏组件优先“屏组件气弹簧支架”，必要时才处理经确认的屏组件支架孔位。不能修改支架结构尺寸来凑距离。
8. 后台计算或读取真实闭合和装配极限，不把当前屏幕姿态当最大角度。用户把门关闭不影响求解最大开启状态。
9. 验证关闭/最大开启距离、压缩与伸长余量、开门方向、机构连接、干涉及力矩。若长度随角度非单调，额外检查行程中的长度极值，端点通过不代表全行程通过。
10. 前框目标50°±5°，两组最大开角差≤3°，关闭余量约10mm；这些来自现有产品规则，新明确要求优先。所用长度必须统一为安装中心距。
11. 支撑计算按铰链轴的力矩分量：重力矩由重心位置与重力叉乘，弹簧力矩由安装点与沿两孔连线的力叉乘，两根分别合计。毫米转换为米；公称力简化、摩擦和风载假设必须说明。
12. 发现不合适应继续选型或调整，不停留在“建议更换”。每次修改后再生、读回和复算。用户要求短行程时，不得悄悄换长行程并称满足。
13. 分别报告两组质量范围、重心、型号、数量、力值、行程、位置、角度、余量、力矩与约束。计算通过、CAD验证通过、实物验证是不同证据，不能互相替代。

用户一次提出SPCC，不代表允许把玻璃、塑料、电子件都赋予SPCC；只对授权且材料适用的钣金结构件处理。
缺失质量的排除授权只允许按说明的范围计算，不证明排除后结果能保证完整实物安全。报告必须保留这一限制。

## 6. 保存、恢复与效率

- 第14步必须落实，不因个别验收未通过直接取消保存；会话健康且可安全保存时保存并附失败清单。崩溃、失联、保存API失败则如实记录未保存，不盲试。
- 保存与清理分开授权。用户仅说保存时回总装配保存，不额外改模型、不默认删除旧版本。
- 超时先查实际结果和文件版本，不能立即重发。新Creo必须重新握手，旧会话身份失效。
- 不擅自重启或升级连接来完成普通修改。日志保留并脱敏；错误后停止危险写入。
- 健康会话复用连接，读取聚焦目标；授权的连续步骤自主完成，不要求用户反复推“下一步”。不承诺未经测量的一分钟时限。

## 7. 历史错误形成的检查清单

| 曾出现的问题 | 必须新增的检查 |
| --- | --- |
| 出风仓请求被当成屏前风扇 | 写入前确认区域、驱动零件和特征 |
| 数量变化后间距未调整 | 数量、种子、间距、两端留白同时验收 |
| 过滤棉框架正确而褶皱越界 | 检查全部几何包络，不只实体 |
| 已发现气弹簧不合适却没换 | 选型必须接实际换型及读回 |
| 门关不上或向后开启 | 关闭余量、方向、死点与约束检查 |
| 把当前姿态当最大角度 | 读取装配极限，后台求解两状态 |
| 玻璃改名后引用缺失 | 保存父装配并验证新名引用 |
| 更新后旧功能不可用 | 匹配服务与DLL能力，逐功能回归 |
| 创建平面壁严重回溯 | 停止写入、保留阶段日志；通信正常不证明创建功能正常 |

这些是纠错知识，不是本次已完成修复的声明。模板驱动的单件建模只是待验证方案，不应写成已经实现的新功能。

## 8. 每次必须输出的执行账本

对每步记录：对象、预期旧值、目标值、实际读回、执行状态、验证证据、保存状态、耗时、失败原因和剩余工作。
状态至少区分：未执行、已读取、已计算、已修改、已符合无需修改、验证通过、验证失败、阻塞；保存状态单独记录。
第8步跳过要留痕；第10/11/12步未满足不能算整体完成；第14步保存成功也不能抹掉未验收项。
