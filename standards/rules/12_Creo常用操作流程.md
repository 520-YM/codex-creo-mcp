# Creo 常用操作流程

本文件记录已经运行、学习或明确批准的标准操作。各流程均先执行《Creo 会话首条命令流程》，并只操作当前 Creo 工作目录。

## 打开与读取

### 打开顶层装配

读取当前工作目录；优先识别“五个0”的最新装配版本；没有时识别其他顶层候选；显示并激活后读回当前模型；同时读取骨架基本信息；默认不保存。

### 读取骨架

从顶层装配定位骨架，读取模型身份、版本、外尺寸、关键特征、尺寸 ID、当前值和方向语义，建立可复用的“名称—特征ID—尺寸ID—用途”映射。

### 屏模型三平面装配

目标屏的“屏横平面、屏竖平面、屏体平面”分别与 `M26Z0181090-V01` 中同名平面重合。约束必须逐项读回验证；已预装配的屏优先使用隐含/恢复切换。

## 壁挂改型14步

1. 读取工作目录、会话、顶层装配、骨架和关键特征。
2. 修改骨架外尺寸并读回。
3. 启用目标屏，隐含其他屏，确保只有一个活动屏。
4. 修改壁挂圆角。
5. 修改玻璃外尺寸、内尺寸；需要时安全改名并同步装配引用。
6. 调整 VESA 孔，先核对横竖坐标，禁止把长宽写反。
7. 调整壁挂草绘：宽固定 400 mm，长度按 100 mm 步进，孔位保持在指定安装区。
8. 适配进风仓和出风仓风扇数量、首位和间距，保证关于中心对称。
9. 从型号库选择 120 mm 宽的 G4/F6 过滤棉，修改 `M26Z0181015-V01` 的“过滤棉孔”。
10. 完整适配前框气弹簧。
11. 完整适配屏组件气弹簧。
12. 适配铰链数量、种子位置和约 300 mm 阵列间距，保证均匀对称。
13. 返回顶层装配，执行受保护的全面重新生成和组件状态审计。
14. 最终验收；所有强制检查通过后才能保存。

## 专项流程

### 玻璃

修改外尺寸与内尺寸；改名必须通过 Creo 模型改名并更新引用，不能只改磁盘文件名。改名能力未验证时可按用户指示只改尺寸。

### VESA

从屏知识库读取孔距；读取模型横竖轴；写入后分别读回两个方向。用户指出方向错误后，该语义映射必须被记录并复用。

### 风扇

区分进风、出风和独立加热风扇；数量变化时重新计算首位与阵列间距；所有普通阵列必须对称；返回顶层重新生成。

### 过滤棉

横屏内贴玻璃户外壁挂只使用宽度 120 mm；区分 G4 与 F6；修改两个未锁定的外形强尺寸；读回后返回顶层重新生成。

### 铰链

按长度适配数量，间距目标约 300 mm；同步骨架孔和阵列；特定五铰链方案将“铰链孔”种子偏移由 200 mm 改为 0 mm；验证数量、间距和对称性。

### 气弹簧模型变型

另存并更新 YQL、YQLUP、YQLDOWN 名称；修改 UP/DOWN 行程、平移轴最大限制和 UP 补偿距离；核对安装孔中心距、直径、开合方向与重新生成状态。

### 模型改名与另存

确认源模型和目标名；拒绝覆盖；通过 Creo API 另存或改名；更新装配引用；重新生成并读回；旧版本删除需单独授权。

### 特征与尺寸读取

返回特征 ID、名称、类型、状态，以及尺寸 ID、符号、数值、关系驱动状态和所属特征。写入前同时核对名称、ID、类型、旧值和方向语义。

## 重新生成、验收与保存

顶层重新生成先核对活动模型名称和类型；强制模式返回通用失败时降级为普通重新生成；审计全部顶层组件状态。最终验收核对尺寸、活动屏、玻璃、VESA、壁挂草绘、风扇、过滤棉、两组气弹簧、铰链、质量范围和重新生成结果。无法由 API 证实的项目列为阻塞，不得报告成功或保存。

## 故障恢复

失败后停止后续写入；报告真实阶段和错误码；执行最小只读诊断；禁止截图/鼠标绕过和长时间盲重试；修改运行时前备份；新版本依次经过静态测试、只读握手、不保存验证和保存验证。
