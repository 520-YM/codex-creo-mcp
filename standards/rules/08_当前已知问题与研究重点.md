# 当前已知问题与研究重点

## 第一优先级

- 修复装配质量与重心读取，避免个别无质量零件导致整套结果失败。
- 读取铰链轴、重心和气弹簧两端安装孔的真实坐标。
- 建立开启与闭合两状态的气弹簧力矩、行程和压缩余量闭环计算。
- 机构求解失败时自动回滚，防止 Creo 回溯或退出。

## 第二优先级

- 第一条命令快速识别新 Creo 会话，不复用已关闭会话。
- 所有工具只读取目标特征，避免加载完整尺寸或组件列表。
- 为每个步骤设置短超时、单次重试和明确错误阶段。

## 第三优先级

- 建立过滤棉完整 Markdown 和 JSON 型号库。
- 建立风扇数量与间距计算公式。
- 建立各尺寸铰链数量和位置表。
- 建立各尺寸壁挂草绘长度表。
- 形成各尺寸两组气弹簧的最终验证参数库。
- 完善玻璃安全改名与装配引用更新。
