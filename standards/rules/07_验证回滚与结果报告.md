# 验证回滚与结果报告

## 写入前

- 核对当前 Creo PID、启动时间、专属管道、工作目录和目标模型。
- 核对目标特征、尺寸符号和旧值。
- 记录当前文件版本和最近一次验证成功状态。

## 写入后

- API 读回新值。
- 检查模型重新生成状态。
- 返回顶层装配再次重新生成。
- 检查组件活动或隐含状态、实际阵列数量、装配约束和关键角度。
- 保存后确认生成的新版本文件。

## 回滚

- 写入失败时优先在同一事务恢复旧值。
- 无法事务回滚时，使用最近一次验证成功版本。
- 旧版本清理采用 Windows 回收站等可恢复方式。
- 不使用不可恢复的批量删除或硬重置。

## 报告格式

每个步骤必须报告：

- 操作对象。
- 原值与新值。
- API 读回值。
- 模型和顶层装配重新生成结果。
- 实际耗时。
- 未完成项、风险与下一步。
