# 安全与授权边界

更新：2026-10-27。适用于所有 Creo 自动化任务；壁挂专用设计参数不自动适用于单个零件。
本次是规则文档更新，不代表运行程序已实现所有保护；执行前仍需核查工具副作用。

## 默认不得执行但可申请授权

以下操作不是永久绝对禁止。确有必要时，必须先说明修改对象、具体内容、原因、风险、验证方法和恢复方式，取得用户明确允许后才能执行：

- 修改 `config.pro`、Codex `config.toml`、MCP 注册、环境配置、插件 DAT、启动脚本、DLL 加载路径或其他配置。不得破坏原生撤销功能。
- 替换、升级或重新注册自研 Creo 桥接 DLL、MCP 服务或连接程序；关闭、重启 Creo 或改变用户当前会话。
- 修改、替换、删除或重新注册 WJT276 插件及其 DLL、DAT 和界面配置。
- 使用截图、屏幕捕获、鼠标点击、键盘输入或固定坐标操作 Creo。
- 引入专用 Creo 启动器、恢复已删除的启动器图标或改变正常启动方式。
- 使用外部桥接替代当前内部 DLL 正式通道。
- 覆盖任务范围外文件、删除模型、清理旧版本或执行不可恢复操作。任务内明确要求的模型修改与正常保存不需要逐次重复授权。
- 操作 86 寸产品自动改型。

授权仅对当次明确说明的操作有效，不自动扩展到其他文件或后续任务。

用户授权完整改型后，范围内读取、计算、修改、再生、验证和保存应连续完成，不要求每一步再次发送“继续”。“始终允许”不自动扩展为修改配置、重启、换桥接或删除数据。
更新 GitHub 文档或代码不等于授权本机部署；不得自动安装、同步覆盖运行目录。

## 始终遵守的连接规则

- 所有功能读取当前 Creo 会话实际工作目录，不绑定 `E:\project` 或任何固定目录。
- 第一条 Creo 命令校验 PID、启动时间、专属管道、工作目录和当前模型。
- Creo 关闭后旧会话立即失效；新窗口不得沿用旧连接。
- 多个 Creo 窗口必须使用各自独立会话，不能相互复用。
- 默认使用内部 DLL 连接，不使用专用启动器。
- 不把“命令已发送”当成“执行成功”。
- 同一 Creo 会话的原生写命令串行执行，前一条未完成时不得叠加重发。超时不等于未执行。
- 握手成功只证明通信正常，不证明建模功能可用。必须核对实际 DLL 协议和工具能力，不以源码目标版本替代加载版本。

## 模型操作边界

- 后盖、前框及屏组件气弹簧支架只修改经核对的安装位置，不修改支架自身结构拉伸长度。
- VESA 长宽方向必须按规则库读取，禁止互换。
- 安装位置的设计目标优先取整数；测量与计算保留精度，最终取整后必须重新校核，产品标准明确的小数不得舍弃。
- 壁挂草绘宽度固定 400 mm，长度按 100 mm 档位变化，且只能位于指定安装区域。
- 过滤棉孔只修改目标未锁定外形尺寸，并保持 G4、F6 等级区分。
- 未经确认，不推算缺失产品尺寸。

本节的 VESA、壁挂、过滤棉限制仅适用于对应壁挂产品，详细参数以规则02—06为准。单个零件任务不强制寻找总装配或套用壁挂14步。

## 保存、清理和异常处置

- 保存与验收分别记录。按用户明确的第14步要求，即使验收未全部通过，也应保存当前可安全保存的状态并标明未通过项目；保存不代表验收通过。
- Creo 崩溃、失联或保存失败时报告保存未完成，不向异常进程反复写入，不覆盖最近有效版本来伪造完成。
- 保存不包含清理授权。调用前检查工具是否附带回收旧版本；不能关闭该副作用时，不得擅自调用并删除历史版本。
- 回溯、空响应、进程消失或机构异常后先停止写入，保留命令、阶段、错误码、会话和保存证据。失败日志不得自动清理；不记录凭据，不未经授权上传日志。
- 只有会话健康、对象和旧值再次核对后才允许受控修正或事务回滚；不能对已崩溃进程执行回滚。
- 不使用截图估算角度或质量替代后台测量；无法核实的项目保持未验证。

## 结果真实性

- 未经 API 读回的修改不得报告为成功。
- 未返回顶层装配，不得报告已返回。
- 未重新生成成功，不得报告已重新生成。
- 未完成质量与力矩校核，不得报告气弹簧能够撑起。
- 空响应、回溯、机构断开、进程消失或重新生成失败时，先检查实际保存状态，不盲目重试。
- 分别报告已读取、已计算、已修改、验证通过/失败、阻塞和已保存；计算结果不能冒充模型读回或完整机构验收。
