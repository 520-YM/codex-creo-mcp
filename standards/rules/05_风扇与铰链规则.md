# 风扇与铰链规则

## 风扇

- 每次尺寸切换重新计算进风仓与出风仓的风扇数量、首个位置和阵列间距。
- 阵列必须左右对称，不能只修改数量。
- 修改后读取实际阵列成员数量，不以输入参数代替结果。
- 从 55 寸改为 65 寸时，用户曾明确要求出风仓增加 1 个、进风仓增加 3 个；反向改型只能在确认起始配置属于该方案后反向减少。
- 2026-10-21 的 V16 只读观察中，`M26Z0181080-V01` 内有 8 个 `FAN-92X38` 和 8 个防护网。该数据是带日期的模型快照，不是所有 65 寸版本的固定标准。
- 同次观察中，后盖装配有 5 个 `M26Z0181079-V01`，但其出风语义尚未验证，不能直接当成 5 个出风风扇。
- 旧的“65 寸出风 6、进风 10”记录与当前模型快照不一致，已降级为历史记录，不得自动套用。
- 没有安全的组件减量与重新均布写入接口时，只报告当前值、目标推导和能力缺口，不得用删除零件特征等不匹配工具代替。

## 风扇适配完成条件

1. 区分进风、出风和独立加热风扇。
2. 核对当前实际成员数量。
3. 根据目标尺寸确定数量。
4. 计算首位和阵列间距。
5. 验证中心对称。
6. API 读回成员数和位置。
7. 返回顶层装配重新生成并保存。

## 铰链

- 铰链数量随产品长度适配，目标阵列间距约 300 mm。
- 铰链必须均匀、对称，并与骨架孔位同步。
- 修改数量时同时检查种子位置、阵列间距和实际成员数。
- 特定阵列方案可要求修改骨架“铰链孔”起始偏移；例如五铰链方案曾使用 0 mm 起始偏移。
- 修改后返回顶层装配重新生成并验证装配状态。
