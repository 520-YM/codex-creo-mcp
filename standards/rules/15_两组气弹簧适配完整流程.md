# 两组气弹簧适配完整流程

2026-10-27执行修订：先读取质量、选择并实际切换型号，再按本文件的支架优先级调整安装位置，最后全面校核。缺材料项允许按用户授权排除且逐项列明，质量与重心保持同一范围，结果不得称完整质量或完整实物安全验收。未授权缺失及未知错误仍阻塞。详见[规则16](16_聊天记录学习与14步严格落实.md)。

更新时间：2026-10-22。

本规则由长期 Creo 操作对话、已确认公司规则和实时 API 读回结果整理而成。适用于横屏内贴玻璃户外壁挂的前框气弹簧与屏组件气弹簧。它不代替实时模型检查；当次指令和现场 Creo API 读回优先。

## 1. 两组气弹簧的对象

### 前框气弹簧组

- 活动门板：`M26Z0141002-V01`。
- 数量：2 根。
- 固定端：骨架中的“后盖气弹簧支架”。
- 活动端：骨架中的“前框气弹簧支架”。
- 优先修改后盖支架安装位置；前框支架必要时允许小范围调整。
- 两个支架只修改安装位置，不修改支架结构拉伸长度。

### 屏组件气弹簧组

- 活动门板：`M26Z0163001-V01`。
- 数量：2 根。
- 第一调整对象：骨架中的“屏组件气弹簧支架”位置。
- 第一调整仍无法满足要求时，才调整 `M26Z0181090-V01` 中“屏组件气弹簧支架孔位”的位置。
- 屏组件与前框在最大开启状态的角度差不得超过 3°。

## 2. 不可缺少的输入

每组开始计算前必须通过正式 API 读取并记录：

1. 当前 Creo PID、启动时间、内部协议、工作目录。
2. 顶层装配、骨架、目标活动件和两根气弹簧的实际模型名。
3. 活动件完整质量及质量来源。
4. 活动件重心坐标。
5. 铰链轴方向与轴线上一点。
6. 固定端、活动端两个安装孔中心坐标。
7. 当前气弹簧中心距、行程、最短长度、推力和数量。
8. 关闭状态和最大开启状态的安装孔距离与开门角度。
9. 当前支架位置尺寸、尺寸方向、旧值和是否关系驱动。
10. 当前机构连接、装配约束和重新生成状态。

缺少质量、重心、铰链轴、孔位或状态几何时，只能报告“尚不能完成力学校核”，不能凭经验宣布适配成功。

## 3. 质量范围

### 前框活动质量

只统计随前框一起绕铰链转动的门板、玻璃、安装件和明确随动组件。固定在后盖或箱体上的组件不计入前框开合力矩。

### 屏组件活动质量

统计 `M26Z0163001-V01` 中随屏组件一起转动的活动组件。只计入当前恢复的屏模型，所有隐含屏不计入。标准屏重量允许使用公司已确认知识库，但必须标注为知识库数据，不能称为 Creo 实测。

### 完整性

- 任一应计实体质量失败时，质量汇总标记为不完整。
- 非实体骨架可以明确跳过。
- 不得为了得到结果而忽略全部失败标准件。
- 应建立两组活动件各自的组件白名单。

## 4. 几何和力学计算

统一使用 SI 力学单位：质量 kg、力 N、距离 m、力矩 N·m；Creo 坐标读取为 mm 时先除以 1000。

### 长度与行程

- 气弹簧完全伸长中心距：`L_ext`。
- 行程：`S`。
- 理论最短中心距：`L_min = L_ext - S`。
- 关闭状态实际孔距：`L_close`。
- 最大开启状态实际孔距：`L_open`。
- 关闭压缩余量：`R_close = L_close - L_min`，目标约 10 mm。
- 开启伸长余量：`R_open = L_ext - L_open`，必须不小于 0；不得靠机构约束强行超过最大长度。
- 有效使用行程：`S_used = L_open - L_close`，必须不大于额定行程。

### 重力力矩

- 重力：`W = m × g`，默认 `g = 9.8 m/s²`。
- 应以铰链轴为基准，将重心到铰链轴的矢量与重力矢量叉乘，再取沿实际开合轴的力矩分量。
- 简化平面计算时：`T_g = m × g × d_g`，其中 `d_g` 是重力作用线到铰链轴的垂直力臂。

### 气弹簧力矩

- 单根气弹簧的力方向沿两个安装孔中心连线。
- 单根力矩应由活动端位置矢量与气弹簧力矢量叉乘，并取沿铰链轴的分量。
- 两根对称气弹簧：`T_s = T_s1 + T_s2`；不能简单用“总推力 × 任意距离”代替真实有效力臂。
- 最大开启保持目标：`T_s / T_g` 建议保留 1.1–1.2 的安全系数，特殊摩擦、风载或密封阻力另行确认。
- 关闭状态必须验证气弹簧开启力矩不会导致门板松手自开。
- 最大开启状态必须验证门板松手不会下落。
- 只比较气弹簧总推力与门板重量，不能证明能够撑起。

## 5. 型号选择

型号格式：

`YQL中心距-行程-UP母头直径-DOWN公头直径-推力`

选型顺序：

1. 根据关闭与开启孔距确定可用的中心距和行程。
2. 保证约 10 mm 关闭压缩余量和非负开启伸长余量。
3. 在满足几何行程的型号中计算所需推力。
4. 从正式型号库选择已有物料，不自行制造不存在的规格。
5. 推力过大导致关门自开或操作力过大时，选择同长度同接口的较小推力。
6. 推力不足导致开启下落时，选择较大推力，或在允许范围内优化支架有效力臂。
7. 型号变化后重新执行全部几何与力矩校核，不能只替换文件名。

气弹簧组件变型必须同步修改：

- 顶层 YQL 装配名称。
- YQLUP、YQLDOWN 零件名称。
- UP 和 DOWN 的行程相关拉伸。
- UP 补偿距离。
- 滑块平移轴最大限制。
- 安装孔中心距与接口直径读回。
- 装配约束、伸缩方向和保存结果。

## 6. 支架位置调整顺序

### 前框组

1. 读取当前型号、两端支架位置、关闭余量和开启角度。
2. 以产品纵向高度约 75% 作为后盖支架的初始搜索参考，尺寸取整数。
3. 优先移动后盖气弹簧支架位置。
4. 若无法同时满足角度、行程和关闭余量，可小范围移动前框气弹簧支架。
5. 仍无法满足时更换中心距或行程，再重新计算推力。
6. 不允许通过修改支架自身结构拉伸长度来“凑”中心距。

### 屏组件组

1. 优先移动骨架中的“屏组件气弹簧支架”。
2. 仍无法满足时，再移动 `M26Z0181090-V01` 中“屏组件气弹簧支架孔位”。
3. 校核自身关闭余量、开启角度和保持力矩。
4. 与前框最大开启角度进行比较，差值不得超过 3°。
5. 不满足时继续优化支架位置或型号，不能只修改机构角度显示值。

75% 是初始搜索参考，不是固定设计结果。最终位置由几何、行程、角度和力矩共同决定。

## 7. 两状态验证

产品机构只按两个用户指定状态验收：

### 完全闭合

- 门板达到真实闭合位置。
- 气弹簧尚有约 10 mm 可继续压缩的余量。
- 松手后门板不会自行打开。
- 气弹簧、支架和相邻零件无干涉。
- 机构约束完整，没有断开连接。

### 最大开启

- 前框目标 50°，允许 45°–55°。
- 屏组件与前框最大开启角度差不超过 3°。
- 气弹簧没有超出最大中心距。
- 松手后活动件不会自行掉落。
- 两根气弹簧受力方向、装配方向和伸缩方向一致。

## 8. 对话中形成的纠错经验

以下是设计经验，不是可直接套用的最终参数：

- 曾出现最大开启角度 59.36°，说明只保证装得上并不能保证目标角度。
- 后盖支架按约 75% 位置调整后曾出现开启角度仅 37.22°，说明 75% 只能作为初值。
- 曾出现关闭压缩余量 68 mm、27.2 mm，随后错误移动又增大到 44.17 mm；每次移动后必须读回余量变化方向，不能凭直觉连续修改。
- 曾发生前框开合方向反转；修改约束、安装端或支架跨越铰链作用线后必须立即验证方向。
- 曾出现“机构断开连接”；这表示几何或约束无法同时满足，点击继续不等于修复完成。
- 550/230、600/255、650/280、765/300 和总长 500 等方案均曾用于理论或试验讨论，除非当前模型重新完成全部验证，否则不能当作对应尺寸的固定标准。
- 前框支架允许小范围调整，但尺寸切换后应能回到该尺寸的初始基准。
- 推力不足时不能只增大推力；推力过大同样会造成关门自开、操作力大或机构异常。
- 气弹簧模型名称正确，不代表内部行程、补偿距离、滑块限制和接口已经正确。

## 9. 失败与回滚

出现以下任一情况时停止继续写入：

- 自动回溯或 `traceback.log`。
- 机构断开连接。
- 开合方向反转。
- 重新生成失败。
- 当前模型、工作目录或会话身份变化。
- 预期旧值与 API 读回不一致。
- 质量汇总不完整。
- 约束、角度、余量或力矩无法读回。

失败后先检查实际保存状态；未保存时恢复本次事务旧值。已保存但验证失败时使用最近一次已验证版本回滚。不得长时间重复同一危险写入，不要求用户反复重启 Creo。

## 10. 完成报告

每组气弹簧必须分别报告：

- 活动件模型与质量来源。
- 质量、重心和铰链轴。
- 气弹簧型号、数量、中心距、行程和单根推力。
- 固定端与活动端支架位置。
- 关闭孔距、理论最短长度和压缩余量。
- 开启孔距、最大长度和伸长余量。
- 实际开启角度。
- 重力力矩、气弹簧力矩和安全系数。
- 关闭不自开、开启不下落的验证结果。
- 机构方向、约束和干涉结果。
- 顶层装配重新生成、保存和读回结果。
- 分项耗时、未完成项和风险。

任一必填项缺失时，状态只能是“未完成”或“试验方案”，不得报告“适配完成”。
